# 🌦️ Weather API Project

## 📌 Project Overview

This project is a **Weather API Project** created using **HTML, CSS and JavaScript**.

The main objective of this project is to understand how APIs work and how to fetch real-time weather data using JavaScript.

For this project, I used the **OpenWeatherMap API** to get weather information for different cities.

---

## 🎯 Project Objective

The main objectives of this project are:

* To understand how APIs work
* To fetch real-time weather data
* To use JavaScript with an external API
* To display API data dynamically
* To handle user input
* To handle invalid city names and API errors

---

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
* OpenWeatherMap API

---

## ✨ Features

* Search weather by city name
* Display current temperature
* Display weather condition
* Display humidity
* Display wind speed
* Display city name
* Fetch real-time weather data
* Error handling for invalid city names
* Responsive and user-friendly design

---

## 🔑 API Used

This project uses the **OpenWeatherMap API** to fetch real-time weather information.

The user enters a city name, and JavaScript sends a request to the API.

The API returns weather information, which is then displayed on the website.

> **Note:** The API key is not included in this GitHub repository for security reasons.

## ⚙️ How It Works

### 1. User Input

The user enters a city name in the search box.

### 2. API Request

JavaScript takes the city name and sends a request to the OpenWeatherMap API.

### 3. API Response

The API returns weather data for the searched city.

### 4. Display Data

JavaScript reads the API response and displays the required information on the webpage.

### 5. Error Handling

If the city is not found or there is an API error, an appropriate error message is displayed.
